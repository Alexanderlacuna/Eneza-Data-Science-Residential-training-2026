The problem we are solving

Clinical need

  • Tall-cell variant of PTC is more aggressive.
  • It is also the rarest class (< 10%).
  • A molecular classifier could triage ambiguous biopsies.

ML challenge

  • Imbalanced 3-class problem
  • ~20,000 genes → feature selection needed
  • Overall accuracy is misleading
  • This iteration establishes metrics & a reproducible baseline.
Progress framing: next iteration will focus on Tall-cell detection and external validation.

Validation workflow — how we keep it honest

Train/test split + 5-fold CV. Feature selection is inside each CV fold to avoid leakage.

  • 80/20 stratified train/test split
  • 5-fold stratified CV on the training set
  • SelectKBest fit only on training folds
  • Final 20% test set used once, after model selection

Metrics that matter for imbalanced cancer data

Class imbalance makes overall accuracy misleading. We use macro F1 and balanced accuracy.

Survival analysis — Kaplan-Meier concept

KM is a step-function estimate of survival probability. A step down is an event; | is a censored patient.

  • S(t) = P(alive at time t)
  • Censored patients contribute up to last follow-up, then leave the risk set.
  • Log-rank test compares observed vs expected deaths across groups.

Survival — annotated subtype

Kaplan-Meier overall survival by pathologist-assigned subtype. TCGA PTC is mostly indolent.

  • Very few death events.
  • Tall-cell curve (n=35) hints at worse survival but is not significant.
  • No pairwise comparison reaches p < 0.05.

Survival — predicted subtype

Kaplan-Meier overall survival by model-predicted subtype. No survival signal emerges.

  • Model predicts more Tall-cell cases (n=57) than annotation (n=35).
  • Even with the enlarged group, curves do not separate.
  • Implication: OS is too weak an endpoint; use recurrence / DFS or molecular markers.
